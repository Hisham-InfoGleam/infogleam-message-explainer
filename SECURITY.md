# Security

## Report a problem privately

If you find a security problem, please report it privately with GitHub
private vulnerability reporting:

1. Open the **Security** tab of this repository.
2. Click **Report a vulnerability**.
3. Describe the problem and how to reproduce it.

Please do **not** open a public issue for security problems.

Do not include real patient data in a report. Use made-up data only.

## What counts

For example:

- A way for the page to send pasted data to a server
- A way to run untrusted script in the page
- A masking bug that leaves a field from the masked list unchanged

## Supported versions

The project is in early development. Only the latest code on the main branch
is supported.
